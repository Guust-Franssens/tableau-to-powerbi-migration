## Premise test
✅ In this repository snapshot, `git ls-files` finds 115 Python scripts and 3 PowerShell scripts; a static AST count finds 85 Python main-guard files and 72 using `argparse` (repository counts, not customer-estate measurements). `pyproject.toml` explicitly calls this a script toolkit and declares no console entry point (`pyproject.toml:45-50`; inventory guard: `tests/test_repo_layout.py:303-319`). The repository already has high-level `start_migration.py` and read-only `run_status.py` routes (`scripts/README.md:38-49,62-77`).

✅ There is measured discovery/help pain: the script index says five scripts were unreferenced before it existed, and a regression test records a stale `--workbooks-only` usage flag and Windows help failures (`scripts/README.md:1-5`; `tests/test_scripts_help.py:7-18`). Those are evidence for keeping the index and help checks, not evidence that agents need another runtime layer. ❌ No repository evidence found that an agent failed a migration because it had to invoke multiple scripts, or that one CLI improves time, tool calls, false claims, or fidelity.

## No-CLI alternative
- **Improve `docs/INDEX.md` and `scripts/README.md` — low, documentation-only cost (⚠️ inferred).** Put the supported journeys and existing entry points first; preserve the README inventory. This directly addresses navigation; it does not create stable CLI JSON or remove script selection logic (`docs/INDEX.md:5-19,47-58`; `scripts/README.md:1-5,38-52`).
- **Generate a script index and check it in CI — medium cost (⚠️ inferred).** Reuse the tracked-file inventory and extend parser-aware help checks. This can reduce hand-copy drift, but does not unify runtime, gates, or exit codes (`tests/test_repo_layout.py:290-319`; `tests/test_scripts_help.py:102-123`; `docs/agent-capability-wiring.md:146-148`).
- **Fix a specific preflight hint only when reproduced — low cost (⚠️ inferred).** Preflight already emits actionable critical-miss hints and nonzero status; no missing-hint case was established here (`scripts/preflight.ps1:85-86,945-952`).
- **Leave things as they are — zero cost.** Keeps current tested entry points and authorities, but accepts existing documentation scan cost (`scripts/README.md:3-5,51-52`).

## Commands that must not exist
- `run-all` / autopilot `migrate`: risks hiding the human credential stop and combines stages with distinct authorities (`AGENTS.md:351-360`; `docs/INDEX.md:7-17`).
- `deploy` / `promote` that hides review or dry-run: existing commands expose distinct checks, tokens, and dry-run options (`docs/INDEX.md:15`; `scripts/deploy_estate.py:1915-1925`).
- Credential/auth helper that enters, stores, or auto-authorizes secrets; any command editing TMDL/PBIR; `update` / `upgrade` that bypasses the session-start timing rule; generic `exec` passthrough. No CLI need is evidenced, and these create new authority or routing surfaces (`AGENTS.md:33-68,351-360`; `docs/INDEX.md:7-17`).

## Decision criteria
Reopen only when **all** hold: (1) at least two comparable blind runs measure lower tool calls or elapsed time than the current documented route, with no increase in false claims or fidelity gaps; (2) every new verb names an existing route it replaces and the net reduction is positive; (3) direct positive/negative tests prove native exit codes, flushed long-running output, and stable JSON; (4) a fresh installed and repo-local invocation preserves `work_dirs` roots, path ceilings, and canonical engine resolution; (5) tests prove credentials still require a human; (6) generated help/route checks catch stale flags and missing agent guidance. Baseline behavior is described in `scripts/README.md:38-52,62-77`, `AGENTS.md:265-268,351-360`, and `tests/test_scripts_help.py:145-173`.

## Kill conditions
Stop or roll back if any command owns a gate verdict, loses native status/output, bypasses a credential stop, accepts secrets in argv, or resolves the engine outside `engine_source.py` (`scripts/check_unit.py:6-18`; `AGENTS.md:262-268,351-360`). Stop if a command has no measurable deleted route, path identity changes, or docs/persona/CI callers must change without a passing compatibility check (`scripts/work_dirs.py:17-26,119`; `.github/workflows/checks.yml:73-97,124-153`). Do not merge this one-file review while its new Markdown path is unindexed; resolving that requires an additional `docs/INDEX.md` change prohibited by this brief (`scripts/check_navigation_index.py:50-66`; `docs/INDEX.md:45-47`; `.github/workflows/checks.yml:83-84`).
